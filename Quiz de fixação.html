📝 Quiz de Fixação — Os Arquivos do AlunosApp

15 questões objetivas sobre o papel de cada arquivo do projeto. Responda com calma, clique em Verificar Respostas no final e veja o gabarito comentado de cada questão.

Respondidas:
15 / 15
1
Qual arquivo é responsável por montar a estrutura visual da tela (título, campos, botões e tabela)?
✅ Correto! O index.html é o esqueleto da tela. Ele contém os campos, o botão e a tabela — mas sem estilo (CSS) e sem lógica (JS).
2
Se o arquivo app.js estiver com erro ou faltando, o que acontece?
✅ Correto! Sem o app.js, ninguém escuta os cliques nem atualiza a tabela. O sintoma clássico é a tabela exibindo ${a.id} literalmente.
3
Para que serve o arquivo style.css?
✅ Correto! O style.css cuida só da aparência. Sem ele, o app funciona, mas fica visualmente "cru", parecido com um site antigo.
4
O arquivo manifest.json é a "carteira de identidade" do PWA. O que ele contém?
✅ Correto! O manifest.json traz nome, nome curto, cores, ícones e o display: standalone, que faz o app abrir em tela cheia.
5
Se o manifest.json não existir, o que o usuário deixa de ver no Chrome Android?
✅ Correto! Sem o manifest.json, o Chrome não reconhece o site como PWA instalável e não oferece "Adicionar à tela inicial".
6
Qual arquivo faz o app funcionar offline, guardando cópia dos arquivos no cache do celular?
✅ Correto! O sw.js (Service Worker) guarda cópias dos arquivos no cache local e responde requisições mesmo sem internet.
7
Se o arquivo sw.js não existir, qual é a consequência mais visível?
✅ Correto! Sem o sw.js, o app não abre offline, o Chrome para de oferecer instalação e o site pode ficar preso em cache antigo.
8
Sobre os arquivos de ícone icon-192.png e icon-512.png, é correto afirmar que:
✅ Correto! Os ícones precisam ser PNG reais nos tamanhos 192×192 e 512×512 — os mesmos declarados no manifest.json. Sem eles, o PWA não instala.
9
O que o arquivo build.yml faz?
✅ Correto! O build.yml é a "receita" que o GitHub Actions executa: publica o site no Pages e gera o APK com Capacitor.
10
Em qual caminho o build.yml deve estar para o GitHub reconhecê-lo?
✅ Correto! O caminho exato é .github/workflows/build.yml. Qualquer variação (sem o ponto, sem o "s", com tab) faz o GitHub ignorar o workflow.
11
Por que o build.yml não pode ter tabulações (Tab), apenas espaços?
✅ Correto! YAML usa indentação como sintaxe. Tabs quebram a leitura e o arquivo é ignorado silenciosamente — sem aviso de erro.
12
Ao editar qualquer arquivo do app, por que é importante trocar alunosapp-v1 para alunosapp-v2 dentro do sw.js?
✅ Correto! A versão no sw.js força o Service Worker a descartar o cache antigo e buscar os arquivos novos. Sem isso, o celular continua com a versão antiga.
13
O mesmo arquivo index.html é usado tanto para o site publicado no GitHub Pages quanto para o app dentro do APK Android.
✅ Correto! O mesmo código HTML é publicado no Pages como PWA e empacotado no APK pelo Capacitor. Isso é o que permite manter uma única base de código.
14
O arquivo app.js é executado tanto no navegador (PWA) quanto dentro do WebView do APK, pois ambos têm motor JavaScript.
✅ Correto! Tanto o navegador quanto o WebView do Android têm um motor JavaScript. Por isso o app.js funciona idêntico nos dois ambientes.
15
Se um único arquivo dos 7 (por exemplo, o sw.js) estiver faltando, o app pode até abrir, mas ficará com alguma funcionalidade comprometida.
✅ Correto! Cada arquivo cobre uma parte específica. Se algum faltar, o app até pode abrir, mas perde uma funcionalidade — offline, instalação, aparência ou lógica.
